# Strategia 1911

Личная историческая стратегия по мотивам PaxHistoria. Вы управляете страной в мире 1 января 1911 года, пишете приказы своими словами, ведёте переписку с другими державами, советуетесь с советником и перематываете время. Последствия моделирует нейросеть, а карта меняется по итогам событий.

Сайт рассчитан на развёртывание в Cloudflare Workers по адресу `strategia.bomverao.com`.

## Что есть в игре

- Два сценария, в каждом можно играть за любую страну (по умолчанию Германия):
  - 1 января 1911 года: 3263 провинции, 60 государств (включая британские доминионы), около 200 городов, армии и флоты великих держав.
  - 1 декабря 1935 года: около 3240 провинций, 73 государства, около 230 городов. Нацистская Германия перевооружается, Италия воюет в Эфиопии, действуют Малая и Балканская Антанты, франко-советский договор, Маньчжоу-Го и советские сателлиты.
- Приказы в свободной форме, кнопки «Идеи» (ИИ предлагает действия) и «Улучшить формулировку».
- Советник с памятью разговора.
- Дипломатия: переписка с одной страной или конференция из нескольких стран, ИИ сам решает, кто отвечает следующим. Страны могут сами написать вам после перемотки времени. Кнопка «Оформить как приказ» превращает договорённости в действие.
- Перемотка времени: до следующего важного события, 1 и 2 недели, 1, 3, 6 месяцев, 1 год или своё число дней. События показываются по одному, на любом можно «вмешаться» и остановить время.
- ИИ меняет карту: передача провинций, аннексии, новые государства, войны, союзы, смена правителей, движение армий.
- Хроника событий, летопись партии (ИИ переписывает её каждые 5 ходов и сжимает старую историю, чтобы не раздувать запросы), таблица стран.
- Хронология с откатом к началу любого прошлого хода.
- Политическая и дипломатическая раскраска карты.
- Настройки: сложность из 6 уровней, выбор провайдера и модели ИИ, редактор всех промптов, читы (приказы всегда успешны, ручной редактор карты, ручная смена отношений).
- Сохранения на сервере в базе Cloudflare D1, доступны с любого устройства после входа.

Платных функций нет. Платить придётся только провайдеру ИИ, если выберете платную модель.

## Провайдеры ИИ

Ключи хранятся в секретах Cloudflare, в браузер они не попадают. Достаточно одного провайдера.

По умолчанию игра работает бесплатно:
- основной провайдер Google Gemini Flash, лучший по качеству среди бесплатных и хорошо пишущий по-русски;
- когда дневной бесплатный лимит Gemini заканчивается (в 2026 году это примерно 20-50 запросов в день) или ключ не задан, Worker сам переключает запросы на Cloudflare Workers AI с моделью Llama 4 Scout. Ей не нужен ключ, бесплатный лимит Cloudflare составляет 10 000 нейронов в день, этого хватает примерно на 10-15 перемоток.

Ключ Gemini выдают бесплатно на aistudio.google.com (раздел Get API key). Если сайт Google AI Studio недоступен в вашей стране, просто не задавайте `GEMINI_API_KEY`: игра будет работать на Workers AI.

| Провайдер | Секрет | Цена | Качество |
|---|---|---|---|
| Anthropic Claude | `ANTHROPIC_API_KEY` | платно, ключ на console.anthropic.com | лучшее |
| Google Gemini | `GEMINI_API_KEY` | есть бесплатный дневной лимит, ключ на aistudio.google.com | хорошее |
| OpenRouter | `OPENROUTER_API_KEY` | платно, есть бесплатные модели с лимитом | зависит от модели |
| Cloudflare Workers AI | ключ не нужен | бесплатно в пределах дневного лимита | слабее, особенно на русском |

Подписка Claude Pro к игре не подключается: она работает только в claude.ai и Claude Code, а сторонние программы обращаются к Claude через API, который оплачивается отдельно.

Ориентир по цене одного хода у Claude (около 15 тыс. токенов на входе и 3 тыс. на выходе): Haiku 5.5 примерно $0.003, Sonnet 5.5 примерно $0.06, Opus 5.5 примерно $0.12. Переписка и советник стоят в несколько раз дешевле перемотки.

## Развёртывание через GitHub (без установки программ)

1. Зайдите в панель Cloudflare, откройте Workers & Pages, нажмите Create и выберите импорт репозитория из GitHub. Укажите репозиторий `Leutnant2823/PaxHistoria` и рабочую ветку.
2. В настройках сборки укажите:
   - Build command: `npm run build`
   - Deploy command: `npm run deploy:ci`
3. Запустите первую сборку. Wrangler сам создаст базу D1 `strategia-db`, применит к ней таблицы из папки `migrations` и привяжет домен `strategia.bomverao.com` (зона `bomverao.com` должна быть в том же аккаунте Cloudflare).
4. Откройте созданный Worker `strategia`, раздел Settings, затем Variables and Secrets, и добавьте секреты:
   - `AUTH_USER` со значением логина;
   - `AUTH_PASSWORD` со значением пароля;
   - ключ хотя бы одного провайдера ИИ из таблицы выше.
5. Откройте `https://strategia.bomverao.com` и войдите.

Логин и пароль не хранятся в коде, потому что репозиторий публичный. Без секретов `AUTH_USER` и `AUTH_PASSWORD` вход не работает.

## Развёртывание с компьютера

Нужен Node.js 20 или новее.

```bash
npm install
npx wrangler login
npm run deploy
npx wrangler secret put AUTH_USER
npx wrangler secret put AUTH_PASSWORD
npx wrangler secret put ANTHROPIC_API_KEY   # или GEMINI_API_KEY / OPENROUTER_API_KEY
```

## Локальный запуск

```bash
npm install
cp .dev.vars.example .dev.vars              # впишите логин, пароль и ключи
node scripts/local-config.cjs              # создаёт wrangler.local.json без Workers AI
npm run db:migrate:local
npm run build
npm run dev:worker                          # http://127.0.0.1:8787
```

С `MOCK_AI=1` в `.dev.vars` в настройках появится тестовый провайдер, который отвечает заготовками без обращения к ИИ.

## Устройство проекта

- `src/worker` Cloudflare Worker: вход по логину и паролю (сессии в D1, ограничение попыток), хранение партий и снимков ходов, прокси к провайдерам ИИ. Worker не разбирает ответы ИИ, а передаёт поток в браузер как есть, поэтому укладывается в лимит бесплатного плана.
- `src/client/game` игровая логика в браузере: состояние партии, применение изменений от ИИ, сборка контекста, промпты.
- `src/client/components`, `src/client/screens` интерфейс на React.
- `scripts/build-map.mjs` сборка карты сценария: провинции Natural Earth накладываются на исторические границы из aourednik/historical-basemaps и правятся таблицами сценария из `scripts/scenarios/<год>.mjs`. Карта 1911 года строится по границам 1914 года (возвращены османские Балканы и Ливия, независимое Марокко, Цин с Монголией и Тибетом), карта 1935 года по границам 1930 года (Саар у Германии, Маньчжоу-Го, независимые Ирак и Египет, Хатай у французской Сирии). Результат лежит в `public/data/map<год>.json`, пересборка нужна только при изменении карты: `node scripts/build-map.mjs 1935`.
- `src/client/game/scenario1911.ts`, `scenario1935.ts` страны, правители, отношения и армии на момент начала сценария.
